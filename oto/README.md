# OTO — 音のプレイグラウンド

**Make a little noise.** 考えるより、鳴らしてみよう。

4つの音と16ステップで、自分だけの短い音楽ループを作れる静的Webアプリです。紙のような背景と、音に反応するグラフィックを組み合わせた、触って遊べる小さな楽器です。

既存のYOHAKUプロジェクトに干渉しないよう、このサイトのファイルは `oto/` 内で完結しています。ルートのREADMEや他サイトのファイルは変更しません。

## できること

- Bell / Keys / Bass / Beat の4トラックを、クリック・タップ・マウスドラッグで編集。
- 再生・停止、60〜160 BPMのテンポ調整、音量調整、トラックごとのミュート。
- Daydream / Afterglow / Nightwalk の3プリセット、おまかせ生成、クリア、最大30編集の取り消し。
- パターン・テンポ・音量をブラウザに自動保存。保存が許可されていない場合も音作りは可能。
- 共有URLにパターン・テンポ・ミュート状態を格納。共有先の再生音量は上書きしません。
- 音に反応するCanvasグラフィック、スマートフォン表示、キーボード操作、動きを減らす設定への対応。

音はWeb Audio APIで合成します。外部ライブラリ、CDN、外部フォント、音声素材、マイク、ログイン、バックエンドは使いません。ページを開いただけでは再生せず、非表示タブでは停止します。

## ローカルで使う

リポジトリのルートで実行します。

```bash
python -m http.server 8000
```

`http://localhost:8000/oto/` をブラウザで開いてください。ビルドや `npm install` は不要です。`oto/index.html` を直接開くこともできますが、保存・共有の確認にはHTTP経由を推奨します。別端末に共有するURLは、公開サイトから作成してください。

## GitHub Pagesで公開する

この実装の追加だけでは、GitHub Pagesの公開設定は変更されません。

リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選び、**main / (root)** を保存してください。独自のGitHub Actionsワークフローは不要です。

公開が完了したら、Pages設定画面に表示されるリポジトリの公開URLの末尾に `oto/` を付けて開きます。すべてのアセット参照は相対パスなので、サブディレクトリでも動作します。

## 操作

| 操作 | 動作 |
| --- | --- |
| マスをクリック・タップ | 音のオン／オフ。停止中はオンにした音を試聴 |
| マウスドラッグ | 複数の音をまとめて描画。1回の「戻す」で取り消し |
| 音の名前 | トラックのミュート／解除 |
| Space | 再生／停止。入力欄やボタンでは標準操作を優先 |
| R | おまかせ生成 |
| 矢印キー | フォーカス中のマスから隣のマスへ移動 |
| Enter / Space | フォーカス中のボタンを操作 |
| ? / Escape | 遊び方を開く／ダイアログを閉じる |

スマートフォンではマスのエリアを横スクロールできます。タッチでのドラッグ描画は行わず、スクロール操作を優先します。

## ファイル構成

```text
oto/
  index.html          ページ構造・操作UI
  styles.css          配色・レイアウト・レスポンシブ対応
  core.js             パターン・検証・共有データの純粋関数
  app.js              UI・音声合成・スケジューラ・保存・Canvas
  favicon.svg         サイトアイコン
  tests/
    core.test.cjs     Node.jsの単体テスト
    dom_test.py       オフラインDOM・実音声出力のテスト
```

## テスト

リポジトリのルートから実行する単体テスト（Node.js 18以上、追加パッケージ不要）:

```bash
node --test oto/tests/core.test.cjs
```

任意のブラウザテスト:

```bash
python -m pip install playwright
python -m playwright install chromium
python oto/tests/dom_test.py
```

`CHROMIUM_PATH` でChromiumの実行ファイルを指定できます。画面キャプチャと結果は `oto/test-results/` に出力します。

作成時に単体テスト7件、ブラウザテスト42項目の成功を確認しました。ブラウザテストはネットワークを使わずHTMLをメモリ内に読み込み、実際のWeb Audio出力と停止後の無音、操作、共有データの復元、320〜1440pxのレイアウトを検証しています。Web Storageは明示的なモックを使用するため、ネイティブの保存権限、HTTP配信、実端末のスピーカー出力、公開後のクリップボード権限はこのテストの範囲外です。
