# 余白 / YOHAKU

アイデア・読書メモ・仕事の記録をまとめる、日本語のブラウザ完結型ノートサイトです。

## 起動

ビルドや依存パッケージのインストールは不要です。

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。`index.html` を直接開くこともできますが、保存先を安定させるためローカルサーバーでの利用を推奨します。

## 機能

- ノートの追加・編集・削除
- タイトル・本文・タグの全文検索
- コレクション別の絞り込み、お気に入り
- 更新日・作成日・タイトルによる並び替え
- グリッド / リスト表示の切り替え
- ライト / ダークテーマ
- JSON形式のバックアップ出力
- キーボード操作とスマートフォン表示

## データについて

データは、このサイトを開いたブラウザの `localStorage` に保存します。サーバー送信・ログイン・端末間同期はありません。初回のみ表示するサンプルノートは編集・削除できます。ブラウザのサイトデータを消去するとノートも失われるため、必要なデータは「バックアップ」で保存してください。バックアップの読み込み機能は含まれていません。

保存領域が利用できない場合は警告し、そのタブを開いている間のみ利用できます。共有端末や機密情報の保存には適していません。

## ファイル

- `index.html`: サイト構造と入力ダイアログ
- `styles.css`: レスポンシブレイアウトとテーマ
- `app.js`: ノート操作・検索・保存
- `tests/test_site.py`: Playwrightを使うブラウザテスト

アプリ本体に外部ライブラリ・CDN・APIキーは不要です。

## ブラウザテスト

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/test_site.py
```

テストは専用の一時ブラウザとローカルHTTPサーバーを使い、普段のブラウザのデータは変更しません。
