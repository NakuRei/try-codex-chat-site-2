# 余白 / YOHAKU

**思いつきを、そのまま置いておこう。**

アイデア、読書の余韻、仕事の気づき、日々の発見を置いておく、日本語のノートサイトです。紙を思わせる淡い色と明朝体の見出しで、静かな自分のノート棚をつくれます。

## 起動

アプリのビルドや依存パッケージのインストールは不要です。

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。保存先を安定させるため、HTMLファイルの直接表示ではなくHTTPサーバー経由で利用してください。

## できること

- ノートの追加・編集・削除、お気に入り
- タイトル・本文・タグの全文検索（空白区切りのAND検索、英数字の全角・半角に対応）
- 4つのコレクションとタグによる絞り込み
- 更新日・作成日・タイトル順の並び替え
- グリッド / リスト表示とライト / ダークテーマ（設定を保存）
- 8つの問いから書き始める「ひらめきの種」（広い画面に表示）
- JSONバックアップの書き出しと読み込み
- スマートフォン表示、キーボード操作、アニメーション低減設定への対応
- 未保存で閉じるときの確認、保存失敗の警告、別タブの変更検知

初回は5件の編集・削除可能なサンプルノートが表示されます。すべて削除しても、再読み込み時にサンプルは復活しません。

## ショートカット

| キー | 操作 |
| --- | --- |
| `N` | 新しいノート |
| `/` または `Ctrl / Cmd + K` | 検索に移動 |
| `Ctrl / Cmd + Enter` | 編集中のノートを保存 |
| `Esc` | 編集画面やメニューを閉じる |

文字入力中・日本語変換中には、新規作成のショートカットは実行されません。

## 保存とプライバシー

ノートは利用中のブラウザの `localStorage` に保存します。サーバー送信、アクセス解析、ログイン、端末間同期はありません。アプリは外部CDN、画像配信、APIキーを使いません。同一ドメイン内の別サイトと混ざらないよう、保存キーをサイトのディレクトリ単位で分けています。

**ブラウザのサイトデータを消すとノートも失われます。** ブラウザ、端末、URLのドメイン・ポート・ディレクトリを変えると保存先も変わります。必要なノートはサイドメニューからバックアップしてください。平文での端末内保存なので、共有端末や機密情報の保存には適していません。

保存容量が足りない場合や保存が禁止されている場合は警告します。その場合、変更はそのタブ内だけに保持されます。読み取れない既存データは自動で上書きしません。未保存の編集中に別タブで同じノートの変更を検知した場合も、上書きせず警告します。共同編集・同時書き込みの完全なトランザクション保証を提供するアプリではありません。

バックアップは既存ノートとマージします。同じIDは更新日が新しい方を採用するため、同じバックアップを繰り返し読み込んでも増殖しません。不正形式のファイルは読み込みません。上限は1,000件、タイトル120文字、本文30,000文字、タグ8個（各24文字）、読み込みファイル10 MBです。実際の保存容量はブラウザの制限にも依存します。

## GitHub Pagesで公開

このリポジトリの **Settings → Pages** で以下を設定すると、ビルドなしで公開できます。

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

`.nojekyll` を同梱しています。独自のデプロイワークフローは不要です。同梱のGitHub Actionsは**テスト専用**で、公開設定やデプロイは行いません。

公式手順: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 構成

```text
index.html                  ページと編集ダイアログ
styles.css                  レイアウト、テーマ、レスポンシブ表示
app.js                      ノート操作、検索、保存、バックアップ
favicon.svg                 オリジナルのロゴ
.nojekyll                   静的配信用
.github/workflows/test.yml  ブラウザテスト
tests/test_site.py         Playwright + unittest（12テスト）
tests/requirements.txt     テスト用依存パッケージ
```

## ブラウザテスト

Python 3.10以降で実行できます。依存パッケージはテストにのみ必要です。

```sh
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
python tests/test_site.py
```

Linuxで必要なブラウザ依存ライブラリも導入する場合は `python -m playwright install --with-deps chromium` を使用してください。既存のChromiumを利用する場合は、`CHROMIUM_EXECUTABLE` 環境変数に実行ファイルのパスを指定できます。

一時的なローカルHTTPサーバーと専用ブラウザプロファイルで、作成・編集・削除・検索・テーマ・JSON往復・入力の安全な表示・保存エラー・別タブの競合・画面幅320〜1440pxなどを確認します。普段のブラウザのノートは変更しません。
