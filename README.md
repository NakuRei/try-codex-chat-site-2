# 余白 / YOHAKU

**思いつきを、そのまま置いておこう。**

アイデア、読書の余韻、仕事の気づき、日々の発見を置いておく、日本語のノートサイトです。このリポジトリではYOHAKUのみを管理し、サイト本体をルートディレクトリに配置しています。

HTML・CSS・JavaScriptだけで動作します。アプリのビルド、パッケージのインストール、ログイン、バックエンドの用意は不要です。

## できること

- ノートの追加・編集・削除、お気に入り
- タイトル・本文・タグの全文検索、コレクションとタグによる絞り込み
- 更新日・作成日・タイトル順の並び替え
- グリッド／リスト表示、ライト／ダークテーマ、スマートフォン対応
- 8つの問いから書き始める「ひらめきの種」（広い画面に表示）
- JSONバックアップの書き出し・読み込み
- 未保存で閉じるときの確認、保存失敗の警告、別タブの変更検知

検索は空白区切りのAND検索で、英数字の全角・半角に対応します。初回は編集・削除可能なサンプルノートが5件表示されます。すべて削除しても、再読み込みでサンプルは復活しません。

## ローカルで使う

リポジトリのルートで実行します。

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。保存先を安定させるため、HTMLファイルを直接開くのではなくHTTPサーバー経由で利用してください。

## GitHub Pagesで公開する

リポジトリの **Settings → Pages → Build and deployment** で、次の設定を保存します。

| 項目 | 設定値 |
| --- | --- |
| Source | Deploy from a branch |
| Branch | main |
| Folder | / (root) |

標準ドメインで公開する場合のURLは次のとおりです。実際の公開状態はPages設定画面で確認してください。

```text
https://nakurei.github.io/try-codex-chat-site-2/
```

`.nojekyll` を同梱しています。独自のデプロイワークフローは不要です。`.github/workflows/test.yml` は**テスト専用**で、Pagesの設定変更やデプロイは行いません。

公式手順: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 保存とバックアップ

ノートは利用中のブラウザの `localStorage` に保存します。ノートをサーバーやGitHubに送信する機能、ログイン、端末間同期、アクセス解析はありません。アプリは外部CDNやAPIキーを使いません。

**ブラウザのサイトデータを消すとノートも失われます。** ブラウザ、端末、URLのドメイン・ポート・ディレクトリを変えると保存先も変わります。大切なノートはサイドメニューの「バックアップを書き出す」で保存し、「バックアップを読み込む」で取り込んでください。バックアップJSONを公開リポジトリに追加しないでください。

ノートは端末内に平文で保存されます。共有端末や機密情報の保存には適していません。保存キーはサイトのディレクトリ単位で分けていますが、アクセス制御や暗号化を提供するものではありません。

保存が禁止されている場合や容量不足の場合は警告し、変更をそのタブ内だけに保持します。読み取れない既存データを自動で上書きすることはありません。未保存の編集中に別タブで同じノートが変更された場合も、上書きせず警告します。ただし、共同編集や同時書き込みの完全なトランザクション保証はありません。

バックアップは既存ノートとマージし、同じIDは更新日が新しい方を採用します。不正形式のファイルは読み込みません。上限はノート1,000件、タイトル120文字、本文30,000文字、タグ8個（各24文字）、読み込みファイル10 MBです。保存可能な容量はブラウザの制限にも依存します。

## キーボード操作

| キー | 操作 |
| --- | --- |
| `N` | 新しいノート |
| `/` または `Ctrl / Cmd + K` | 検索に移動 |
| `Ctrl / Cmd + Enter` | 編集中のノートを保存 |
| `Esc` | 編集画面やメニューを閉じる |

文字入力中・日本語変換中には、新規作成のショートカットは実行されません。


## テスト

テストにはPython 3.10以降とPlaywrightを使用します。依存パッケージはテストにのみ必要です。

```sh
python -m pip install -r tests/requirements.txt
python -m playwright install chromium
python tests/test_site.py
```

Linuxでブラウザの依存ライブラリも導入する場合は `python -m playwright install --with-deps chromium` を使用してください。既存のChromiumは `CHROMIUM_EXECUTABLE` 環境変数で指定できます。

一時的なローカルHTTPサーバーと専用ブラウザプロファイルを使い、ノート操作、検索、テーマ、バックアップの往復、入力の安全な表示、保存エラー、別タブの競合、画面幅320〜1440pxを検証します。普段のブラウザのノートは変更しません。

GitHub Actionsでは `main` へのpushとpull requestでJavaScriptの構文チェックとブラウザテストを実行します。Actions画面から手動で実行することもできます。
